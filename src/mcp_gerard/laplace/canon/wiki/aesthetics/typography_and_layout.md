# Typography and Layout constraints

* **The Two-Column Mandate**: Figures must be explicitly designed for standard two-column formats, maintaining legibility when shrunk to a single column width. If absolutely necessary, explicitly force a single-column spanning figure `\begin{figure*}`. See [figure_standard](canon://skills/figure_standard) for exact column-width sizing.
* **Data Legibility**: Tables must be refined for absolute legibility. Strictly use the `booktabs` package conventions (no vertical lines, minimal horizontal lines).
