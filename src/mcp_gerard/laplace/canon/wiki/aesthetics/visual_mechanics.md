# Visual Aesthetics: "Nature-Style Hero Figures"

Figures are geometric proofs of the architecture. Let the visual structure and LaTeX captions do the heavy lifting.

* **The "Child Made It" Rule**: Zero tolerance for default charting aesthetics, overlapping text, disproportionate fonts, or PowerPoint drop shadows.
* **Ultra-Premium Polish**: Visuals must mimic the highest-impact journals (*Nature*, *PRX*). Vector graphics (TikZ) are strictly preferred - use [tikz_mechanic](canon://skills/tikz_mechanic/SKILL.md) to sanitise color syntax before compilation. Demand elegant node styles, muted vermilions, deep macro-scale blues, clean flat pastel fills (`blue!10`), and thick dark outlines (`blue!80!black`). 
* **Iterative Perfection**: Visuals must survive a minimum of two independent subagent review cycles to guarantee perfection before presentation. See [figure_standard](canon://skills/figure_standard/SKILL.md) for the production discipline these cycles check.
